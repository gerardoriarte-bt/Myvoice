- **Falta**: una generación real con una marca que tenga prohibiciones propias, para confirmarlo. No se
  corrió porque gasta crédito.
- **Lo que salió mal al mergear**: los PRs #45, #46 y #47 estaban apilados. Al borrar la rama del #44,
  GitHub cerró el #45 en vez de reapuntarlo a `main`, y el script siguió y mergeó el #46 dentro de la
  rama del #45, lo que cerró el #47. No se perdió nada: la rama del #47 tenía todo y entró como el #48.
  Para la próxima: con PRs apilados, reapuntar cada uno a `main` (`gh pr edit N --base main`) **antes**
  de borrar la rama del anterior, y que el script se detenga si un PR no apunta a `main`.
